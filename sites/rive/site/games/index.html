Make games with artist tools and AI

Rive is an agent-native game engine and AI game maker. Describe your game and your coding agent builds all of it with the Rive CLI. Shape the art and motion by hand in the Rive Editor when you want, then publish natively to mobile, desktop, Steam, consoles, and the web.

Show the game UI on a responsive 3D visor HUD: draw the visor with GPU Canvas and build the HUD with Rive Layouts so it fits any screen. Ship natively to every platform

Game features

Everything your game needs in one engine

Everything your game needs in one engine

Rive covers the art, motion, logic, and audio. Your agent builds with these tools through the Rive CLI, and you refine it in the Rive Editor.

State Machine

Wire game states, enemy behavior, and menus visually, so the logic lives next to the art.

Data Binding

Bind score, health, and inventories to a view model, and use lists for anything that repeats.

Responsive Layouts

Fit every screen, from a phone to a TV, with layouts that resize and reflow.

Joysticks

Map timelines to a handle’s X and Y to rig head turns, eyes, and poses for characters.

Timeline

Professional timeline tools for characters, effects, and menus. Animation plays live and blends at runtime.

Scripting

Write gameplay, procedural motion, and custom drawing in AnimaScript, right inside Rive.

Audio Events

Trigger sound effects from a keyframe, a state transition, or a listener.

Scrolling Lists

Scroll level selects, inventories, and leaderboards with momentum. Virtualized lists only build the rows on screen, so long lists stay fast.

Text Input

Add fields for player names and chat. Players click or tab in, type, select, and paste.

Gamepad

Play with a controller. Gamepad listeners react to buttons and sticks, and Focus moves through menus in order.

Localization

Swap every string per language through Data Binding. Layouts flip for right-to-left languages, and fallback fonts cover missing glyphs.

Rive Renderer

Vector, raster, and 3D in one scene

Vector, raster, and 3D in one scene

Put 2D characters and UI in 3D worlds with cameras, lights, and shaders. The Rive Renderer draws a huge number of vectors with analytic antialiasing, so shapes and text stay crisp at any size and resolution. Vector Feathering adds soft edges and glows without the cost of a blur. Your game’s art, motion, and logic ship in compact .riv files.

FAQ

Questions about making games in Rive

Questions about making games in Rive

Can I make a game with AI in Rive?

Yes. Install the Rive CLI and describe your game to your coding agent. It builds a Rive file and opens the CLI preview window on your screen, no account needed. Keep directing it, or open it in the Rive Editor to draw, animate, and rig by hand.

Is Rive a 2D game engine?

Rive is a 2D and 3D game engine. One scene holds vector, raster, and 3D with cameras, lights, and shaders, plus State Machines, Data Binding, audio, and scripts in AnimaScript.

Which platforms can I publish my game to?

iOS, Android, Windows, macOS, Linux, Steam and Steam Deck, and the web, all through the Rive C++ runtime. Runtimes for PlayStation 5, Xbox Series X, and Nintendo Switch are available on request.

How is Rive different from an AI game generator?

You get a game you keep building. It lives in Rive, and you change it with your agent or by hand in the Rive Editor, and it ships as a native app on every platform.

Which AI agents work with Rive?

Any coding agent that can run command line tools, including Claude Code, Codex, and Cursor. Your agent installs the Rive CLI from rive.app/cli and builds from there.

Is Rive free to make and ship games?

You can start free. The free plan covers building in the Rive Editor and the Rive CLI, with usage limits. Free exports play a Rive splash screen, and exporting without it needs a paid plan. The runtimes are open source under the MIT license, with no royalties or revenue share.
