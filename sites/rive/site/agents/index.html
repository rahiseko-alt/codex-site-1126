Rive for agents

Build Rive with your AI agent

Build Rive with your AI agent

The CLI builds Rive files from Rive Markup Language (RML), plain-text .rml files that agents can read and write. No sign-in and no account needed to get started.

CLI docs

Watch the walkthrough

Check what you built

Confirm a scene compiles, inspect what it contains, render frames without a window, and drive it with real or simulated input and data. Run the same checks in CI.

Text you can diff

A project is a folder of plain text and assets, so it lives in Git or Perforce next to your app code, and every change reviews as a readable diff.

Work offline

Write, preview, verify, and test without a connection. Sign in to publish or sync with the Rive Editor. Publishing compiles and signs your scripts, and runtimes refuse any script that isn’t signed.

AnimaScript

Scripts your engineers can sign off on

Scripts your engineers can sign off on

AnimaScript is Rive’s scripting language: TypeScript syntax, compiled to WebAssembly. Edit the code below: the compiler runs in your browser.

Read the docs

See the benchmarks

Reviewed like your code

Every script is a .as text file in your repo. Engineers, Copilot, or your own agent review it in a pull request, with the same approvals as everything else you ship.

Signed

Publishing signs your scripts. Runtimes refuse scripts that are unsigned or changed after signing.

Sandboxed

Scripts run in a WebAssembly sandbox and only reach the Rive APIs the runtime gives them. A bad pointer stops the script instead of touching your app’s memory.

Tested in CI

Write tests next to your scripts and run them headless with rive --test. A failing test fails the build.

Near native speed

Compiled ahead of time, AnimaScript decodes Draco meshes 8.7× faster than the previous scripting runtime. Existing scripts keep working.

// Edit any number: the scene recompiles as you type.
declare function dot(x: f32, y: f32, r: f32, a: f32): void;

struct Vec2 {
    x: f32;
    y: f32;
}

function orbit(i: i32, t: f32): Vec2 {
    const k = <f32>i;
    const angle = t * (0.3 + k * 0.004) + k * 2.399;
    const radius = 16.0 + k * 0.42;
    let p = Vec2();
    p.x = Mathf.cos(angle) * radius;
    p.y = Mathf.sin(angle) * radius * 0.6;
    return p;
}

export function frame(t: f32): void {
    const count = 360;
    for (let i = 0; i < count; i++) {
        const p = orbit(i, t);
        const fade = <f32>i / <f32>count;
        dot(p.x, p.y, 1.0 + fade * 1.6, 0.25 + fade * 0.75);
    }
}

Two ways to work

Pick how your agent works with Rive

Use one, or move between them on the same project.

Rive CLI

Your coding agent builds and edits Rive files from text, checks its work, and exports. Works with any agent that runs shell commands. No account needed to start.

Built-in AI Agent

Ask the agent inside the Rive Editor to write scripts, build layouts and data models, and animate. Every plan has it: Free and Cadet get a preview, Voyager and up get the full feature set.

Agent setup

Works with the agent you already use

The same starter prompt works everywhere.

Claude Code

Paste the starter prompt and Claude Code installs the CLI. Projects come with a CLAUDE.md, so Claude knows how to check its work.

Codex

Paste the starter prompt and Codex installs the CLI. Projects come with an AGENTS.md, which Codex reads when it opens the folder.

Cursor

Open the project folder in Cursor and paste the starter prompt. Cursor reads AGENTS.md.

Any other agent

Hermes, OpenClaw, and any agent that can edit files and run shell commands work the same way.

How to get started

Direct your agent. Then shape it by hand.

Start with one prompt in your coding agent. It installs the Rive CLI, builds a first version, and opens the CLI preview window on your screen, no account needed. Keep directing it, or open it in the Rive Editor for professional design and animation tools: rigging, timelines, state machines, and data binding.

Works with Claude Code, Codex, Cursor, Hermes, OpenClaw, and other agents that run on your computer. macOS (Apple Silicon), Windows, and Linux.

FAQ

Questions about agents in Rive

Questions about agents in Rive

What to know before you paste the first prompt.

Which agents work with it?

Claude Code, Codex, Cursor, Hermes, OpenClaw, and other coding agents that run on your computer. Paste the starter prompt and the agent installs the CLI.

Do I need a Rive account?

You can build and preview without one. Sign in to publish or export a file, open it in the Rive Editor, or go past the free usage limits.

What does the CLI build?

A .riv file from Rive Markup Language, scripts, shaders, and assets, with vector and 3D graphics, state machines, data binding, and layouts that play on Rive’s runtimes.

Which platforms does it run on?

The CLI runs on macOS (Apple Silicon), Windows, and Linux. The files it builds run on web, iOS, Android, desktop, and game engines.
