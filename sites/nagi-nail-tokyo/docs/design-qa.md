# Paintbox のテーマを使った日本向けトップ

[元の取得・比較記録](../../paint-box/docs/design-qa.md)

`theme/index.source.html` から生成したトップのタグ、クラス、ID、スクロール演出の `data-aos` を照合した。テーマJavaScriptとベンダーバンドルは取得済みの Paintbox 版とバイト単位で一致する。テーマCSSは配色のカスタムプロパティの値だけを書き換える。

| トップの箇所 | 動作と差し替え内容 |
| --- | --- |
| 告知帯・ナビ | 日本語の告知とワードマーク。元の追従ヘッダーと検索・バッグの表示 |
| 全幅スライド | 新しいロングとショートの写真。元の7秒切り替え、写真の横移動、見出しのせり上がり、CTAの遅延表示 |
| 商品5件 | 新しい商品画像、商品名、円価格。元のグリッドの横入り、時間差フェード、ホバー切り替え |
| レビューと掲載枠 | 元のレビュー用要素を保持。外部購入者レビューの埋め込みは外した。掲載枠はロゴ7点をオリジナルの色名イラストに差し替え、元の時間差表示を引き継ぐ |
| 特集2枚・ギフト・SNS紹介 | 新しい写真、手の線画、GIF。元の配置と写真フェード |
| 登録欄・フッター | 日本語の案内。元のスマホ用フッターアコーディオン |
| 初回ポップアップ | 元の20秒タイマー。文章とイラストを新作案内に差し替え |

本番の注文、決済、予約、メール登録、元店舗のアナリティクスは接続していない。画面から送信操作をすると、サイト内デモで結果を確認できる。

Chromium の PC（1440 × 900）とスマートフォン幅（390 × 844）で、元のヒーロー自動送り、追従ヘッダー、商品グリッドのスクロール発火、ポップアップと商品リンクを確認した。PCでは商品画像のホバー切り替えも確認した。
