# 日本向け版の構成と動作

元の Paintbox トップの HTML とテーマの設定は [再現版の検証記録](../../paint-box/docs/design-qa.md) に対応しています。

| Paintbox トップの順序 | nagi nail studio |
| --- | --- |
| 告知帯とナビゲーション | 告知帯、カテゴリ、検索、バッグ、予約 |
| 全幅スライド2枚 | ロングとショート。7秒ごとのフェード、手動切替、一時停止、タッチスワイプ |
| 商品5点 | ネイルチップ5点。ホバー画像、長さで絞り込み、商品詳細、税込価格 |
| レビュー枠と掲載ロゴ | つけ方のヒントと色の手帖 |
| 特集2枚 | ジャーナルと代々木上原のスタジオ |
| ギフトとSNS紹介 | ギフトとネイルデザイン。写真と文章の左右を入れ替えて配置 |
| ニュースレターとフッター | 登録確認デモと、サポート・デザイン・スタジオのリンク |

商品、特集、ギフトの画像や文字がスクロールで画面に入ると順番に表示されます。端末で動きを減らす設定を選んだ場合は、自動送りを停止した状態で表示します。商品価格・場所は架空の設定です。注文、決済、予約、メール送信は行いません。

## 確認

Chromium の PC（1440 × 900）とスマートフォン（390 × 844）で、スライド切替、表示演出、商品詳細とバッグ、検索、日本時間での予約確認、ニュースレターを確認しました。
