Skymetrics

2024 ::: Data

A dashboard for Skymetrics — an AI-powered product intelligence platform for Shopify merchants.

:: Role

Product Design

:: Team

Client product team

:: Timeline

6 weeks

:: Services

Dashboard design / UX

:: Platform

Web app, desktop

(01)

Skymetrics helps Shopify merchants understand their products: what performs, what’s running low, and what to do next — with AI doing the heavy analysis.

(02)

The challenge was density. A lot of data had to fit on one screen and still lead the user to a clear decision.

:: / APPROACHBuilt backwards from decisions.

01 —

Audit

Which numbers merchants check every day, and which ones they ignore.

02 —

Architecture

A clear hierarchy: overview first, product detail one click away.

03 —

Wireframes

Every widget tested against one question: what decision does it help make?

04 —

UI design

Neutral base, colour only for change, AI insights in plain language.

:: / FINDINGS

Calm data

A calm, neutral base lets the important numbers stand out. Colour is used only to signal change, and AI insights are written as short, plain-language suggestions.

Every widget has to earn its place on the screen.

— design principle

:: / DETAILSSmall things that carry the idea.

:: / OUTCOMEWhat changed. What comes next.

Final Result

A dashboard that turns raw store data into clear next steps, helping ecommerce teams act on insights instead of digging for them.
