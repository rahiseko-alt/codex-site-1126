(01)

AI /M/ Assistant is a marketing tool that uses AI to shape how data is shown, based on what each user cares about most.

(02)

The main task was to show this flexibility clearly — how the interface adapts and how users customise their workspace.

:: / FINDINGS

Motion tells the story

Widgets appear, resize and regroup to show personalisation in action, while the interface itself stays clean and calm.

:: / APPROACHFlexibility made visible.

01 —

User flows

How different marketers set up and use their workspace.

02 —

Direction

A clean, calm interface where motion explains the changes.

03 —

UI design

A modular widget system that adapts to each user.

04 —

Motion

Animation that shows the dashboard rearranging itself.

Let the interface show how it adapts — not explain it.

A clear demonstration of an adaptive AI product, where design and motion make complex personalisation easy to understand.
