# Chillhouse Soho 検証記録

元サイトの Shopify の公開 HTML、テーマ CSS、JavaScript を確認した。公開版は取得時点の内容を表示する。対象の URL は [収録ページ一覧](routes.txt) を参照。

公開版では予約、購入、登録、問い合わせの操作を公式サイトへ引き継ぐ。外部機能の表示は配信元や地域に依存する。
