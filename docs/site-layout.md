# サイトの整理ルール

新しいサイトは `sites/<slug>/` に追加します。 `<slug>` は他のサイトと重複しない、英小文字とハイフンを使った名前です。

- そのフォルダに、動かすためのコード、素材、依存関係の宣言とロックファイル、ビルド設定を置きます。依存関係のインストールもビルドも、そのフォルダで完結させます。
- サイト自身の README に元サイトと公開版のURL、必要な実行環境、起動・ビルド・確認方法、デプロイ先、再現できていない挙動を書きます。比較画像や詳細な検証記録も同じフォルダに置きます。
- デプロイ設定はサイトごとに持ち、対象フォルダから生成した成果物だけを、そのサイトの公開先へ送ります。既存サイトのプロジェクトIDやトークンを別のサイトに使い回さないでください。
- [ルートの README](../README.md)にはサイト名とサイト自身の README へのリンクだけを追加します。
- 追加後は新しい checkout から対象フォルダに入り、手順どおりに起動とビルドができることを確認します。複数を同時に確認するときは別々のポートを指定します。

最初の例は [Carter Ogunsola ポートフォリオ](../sites/carter-ogunsola/README.md) です。
