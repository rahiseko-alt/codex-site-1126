# 引き継ぎメモ

セッションをまたいで作業を再開するための記録。**新しいものを一番上に足す。**

- 1件の区切りは行頭の `## `。書式は `docs/agents/flow-map.md` の「引き継ぎメモ」に従う。
- 保存の上限と、会話開始時に読み込む件数は `.claude/hooks/session-start.sh` が持つ。
- 追記したら `sh .claude/hooks/handover-trim.sh` を実行して件数を整える。
